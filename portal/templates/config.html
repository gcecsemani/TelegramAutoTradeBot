Lot size and slippage

These rules apply to every account. A named symbol replaces *. Lot size is the range this account's cash falls in. Both ends count. Cash already in a position is not subtracted, so one trade does not shrink or block the next. It only chooses the lot size.

Balance ranges

NIFTY, SENSEX and BANKNIFTY start at ₹35,000–₹50,000 for 1 lot, then step up. CRUDE, GOLD, SILVER, natural gas and every other name use *, which starts at ₹100,000–₹199,999 for 1 lot. A balance outside every range for that symbol takes no trade. Add the next range here when you want a higher lot count.
